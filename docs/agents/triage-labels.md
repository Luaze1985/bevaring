# Triage Labels

| Role | Local label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and agent-ready |
| `ready-for-human` | `ready-for-human` | Needs human decision or sensitive context |
| `wontfix` | `wontfix` | Will not be actioned |

Use these labels in local Markdown issue files.
